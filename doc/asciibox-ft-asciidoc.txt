------------------------------------------------------------------------------
Overview					*asciibox-ft-asciidoc-overview*

	Add asciidoc file support for
	- Preview using gp
	- Goto file using gf

	Add open link support for gx



------------------------------------------------------------------------------
Configuration 					*asciibox-ft-asciidoc-config*

	To avoid default browser for preview use this:
	let g:asciibox_browser = 'firefox' 
	or
	let g:asciibox_browser = 'goggle-chrome-stable'
