------------------------------------------------------------------------------
Overview					*asciidoc-ft-overview*

	Support 
	- gf (goto file),gp (preview), gx (open link)
	- Efficient folding support
	- filename completion after specific asciidoc macro


------------------------------------------------------------------------------
Mapping						*asciidoc-ft-mapping*
	MODUS	MAPPING	DESCRIPTION
	n	gf	open file under cursor. Ignore link,include and xref macro 
	n	gp	preview. Open asciidoc viewer. Use a:asciibox_browser
			to change default browser
	n	gx	follow link. Open browser
	n	<LocalLeader>z	Redraw folding
	i	ctrl_x ctrl_f offer filename completion

------------------------------------------------------------------------------
Configuration 					*asciidoc-ft-config*

`g:asciidoc_browser`				*asciidoc_browser*
	Type: |String|
	Standard: empty
	To avoid default browser for preview use this:
	let g:_browser = 'firefox' 
	or
	let g:_browser = 'goggle-chrome-stable'

`g:asciidoc_folding`				*asciidoc_folding*
	Type: |Int|
	Standard: 1
	Set it to 0, to disable folding

g:asciidoc_image_extensions			*asciidoc_image_extensions*
	Type: List
	Standard: 'png', 'jpg', 'jpeg', 'gif', 'svg', 'webp'
	To reduce or extend this list
	let g:asciibox_image_extensions = ['png', 'jpg', 'svg']

g:asciidoc_include_extensions			*asciidoc_include_extensions*
	Type: List
	Standard: 'adoc', 'csv', 'java', 'py', 'sh', 'vim', 'json', 'xml', 'html', 'css', 'js', 'ts', 'c', 'cpp', 'txt'
	To reduce or extend this list
	let g:asciidoc_include_extensions = [ 'adoc', 'csv', 'yml', 'java' ]
